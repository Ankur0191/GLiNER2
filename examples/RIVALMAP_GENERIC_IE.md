# Generic Rivalmap IE architecture

The old Lifestyle example remains supported. New work lives in
`rivalmap_ie/` as an industry-neutral extraction layer with data-driven
profiles. It currently ships Lifestyle and Testing, Inspection & Certification
(TIC) profiles. Future industry packs are JSON-only unless they need new
application behavior.

See [rivalmap_ie/README.md](../rivalmap_ie/README.md).
